Course overview

Course briefing

Audience

New security engineers who can read Python and HTTP requests.

Prerequisites

A browser and Python 3. No packages, account, or production credentials are required.

Current release

5 of 27 planned lesson pages are published. The remaining chapters are visible in the roadmap and are not presented as completed training.

Delivery

Self-paced reading, runnable local labs, and short knowledge checks. The full course duration will be set when all planned lessons are authored.

Learning outcomes for the published release

  • Identify API credentials exposed in URLs and logs, and move authentication to an appropriate request header.
  • Explain what an HMAC request signature proves, what it cannot prove, and how timestamp and nonce checks limit replay.
  • Run the published Python labs and interpret their accept and reject outcomes.
  • Use the published checklist items during a basic API security design review.

Assessment and completion

For the current release, completion means marking each published lesson complete and passing its quick check. The browser records those actions only on this device. Quick checks give immediate feedback, but they are not proctored and do not issue a certificate, manager report, or authoritative training record.

The site uses semantic headings, descriptive links, and a visible keyboard focus indicator. It has not received a formal accessibility or LMS conformance audit.
