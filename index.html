API security learning path

For new security engineers. Each module starts with a real attack, shows why it works, teaches the control that stops it, and ends with a test you can run. The second half of each page is a reference you can use in design reviews.

Work through the modules in order. Each one assumes the ones before it. Labs need Python 3 and nothing else.
