# v1.0.0

The first tagged release of API Security in the Age of AI.

## What is in it

- 38 lessons, modules 0 to 37, in a primer, six parts and a design review.
- 38 labs, one per lesson. Python 3 with the standard library, except the five labs that need `cryptography` (modules 3, 5, 6, 7 and 36).
- A review checklist of 325 items: 68 Critical, 165 High, 92 Medium.
- A glossary of 202 terms.
- A coverage page that lists each entry of the three OWASP lists the course pins, the lessons that cite it, and what the course leaves out.

## How the checklist severities were set

Each checklist item has a default severity set with a written rubric, version 3.1, which is in `CONVENTIONS.md` and summarised on the checklist page. All items were rated again against it before this release by two raters who could not see the earlier levels. Both raters were the same language model, so their agreement (98.2% on class, 92.4% on severity) overstates what independent human reviewers would reach. The course owner reviewed a sample and the full result, and set three items directly. `AGENTS.md` records the detail under Decisions.

A default severity is a starting point. It is not the severity of a finding in your review.

## What the attached evidence is, and is not

The release workflow runs every repository check with nothing allowed to skip, compares every published lab transcript with a live run, runs each lab in a browser, and runs automated accessibility checks on every page in light and dark mode at two widths. The record of that run is attached to this release.

It describes one run on one system. It is not a certification. The browser checks use Chromium only; no other browser was tested. Automated accessibility rules are a floor and not a conformance claim.

## Known limits

- OWASP LLM07:2026, Misinformation, is not covered. The coverage page says so and lists what else is left out.
- The course teaches design review from documents and small labs. It does not replace testing a running system.
- The module 37 lab does not implement XML Signature. It uses a stand-in that keeps the one property the wrapping attack depends on, and the lesson says so.
